# Programação Orientada a Objetos

Repositório criado para armazenar as atividades e exercícios desenvolvidos na disciplina de **Programação Orientada a Objetos (POO)**.

## 📚 Sobre a disciplina

Durante a disciplina, são estudados conceitos da Programação Orientada a Objetos utilizando a linguagem **Java**.

## 💻 Conteúdos estudados

 Classes e objetos
 Atributos e métodos
 Construtores
 Encapsulamento
 Getters e setters
 Sobrecarga de métodos
 Sobrecarga de construtores
 Herança
 Polimorfismo
 Modificadores de acesso
 `this`
 Métodos `toString()`

## 🗂️ Atividades

Este repositório contém os exercícios e atividades desenvolvidos durante as aulas, com o objetivo de praticar e aprender os conceitos de Programação Orientada a Objetos.

## 🛠️ Tecnologias utilizadas

Java
Geany
Git
GitHub

## 🎯 Objetivo

Praticar programação em Java e desenvolver uma melhor compreensão dos conceitos de Programação Orientada a Objetos.
